# Secure Authentication Lab

## Cyber Security Internship – Task 3

This project demonstrates basic defensive authentication controls for a local Flask authentication service.

## Objective

The objective is to demonstrate:

- Password hashing
- Server-side input validation
- Secure cookie settings
- Logout
- Session expiry
- Login rate limiting
- Generic authentication errors
- Automated security-related tests

## Technologies

- Python
- Flask
- Flask-Limiter
- Pytest
- Werkzeug password hashing
